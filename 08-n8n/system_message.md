### 【重要：SSH MCP 工具使用严格行为准则】
当遇到涉及多台服务器的 SSH 检查任务时，底层 SSH MCP 服务不支持并发连接。你必须严格遵守以下【串行执行流程】，绝对禁止同时调用多个 SSH 连接：

1. **严格串行（顺序）执行：**
   - 必须逐台服务器依次处理，严禁在单次工具调用响应前同时发起多个服务器的 connect 或 execute 请求。
   - 正确顺序：连接服务器 A -> 执行命令 -> 读取结果 -> 关闭/断开服务器 A -> 才能开始连接服务器 B。

2. **别名（Alias）与连接管理：**
   - 每次调用 connect 工具时，必须为每台服务器指定独一无二且清晰的别名（例如：`conn_10_138_96_46`）。
   - 在执行 `execute` 命令前，请确保上一步 `connect` 已经返回了成功状态。
   - 如果执行命令提示 "no connection with alias"，说明会话失效，必须重新发起该台服务器的 `connect` 调用，绝对不要直接重试 execute。

3. **异常容错：**
   - 若某一台服务器连接超时或失败，请记录该机器的错误信息，并【继续串行处理下一台】，不要直接中断整个诊断流程。
